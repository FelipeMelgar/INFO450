# INFO 450: Senior Design Studio

Welcome to the repository for **INFO 450** at Virginia Commonwealth University (VCU). This course serves as a capstone experience where students apply information systems development concepts, methodologies, and technical skills to real-world software engineering and design projects.

---

## 📌 Course Overview

* **Course Title:** INFO 450 – Senior Design Studio / Advanced Systems Development
* **Institution:** Virginia Commonwealth University (VCU)
* **Department:** Information Systems (School of Business)
* **Description:** Integration of systems analysis, design, and implementation techniques. Teams analyze, design, build, test, and deploy software solutions, leveraging modern development frameworks, databases, and agile project management techniques.

---

## 🚀 Key Learning Objectives

* **Full-Stack Development:** Build scalable end-to-end applications using modern tech stacks.
* **Agile & DevOps:** Implement version control, CI/CD pipelines, and collaborative workflows with Git and GitHub.
* **Database Management:** Design structured schemas, optimized queries, and API integrations.
* **Project Delivery:** Collaborate in team settings to present a polished, client-ready software product.

---

## 🛠 Tech Stack & Tools

* **Frontend:** React, HTML5, CSS3, JavaScript / TypeScript
* **Backend:** Node.js, Express, Python / Django, or C# / .NET
* **Database:** PostgreSQL, MySQL, or MongoDB
* **Version Control & CI/CD:** Git, GitHub, GitHub Actions
* **Deployment:** Heroku, Vercel, AWS, or Azure
